# Your files and where they live

## One book, one file

A book is a single file ending in `.draftline`. Inside it: your chapters,
front and back matter, the planner, the cast, your editions and their cover
art, and earlier versions of chapters you have revised.

You chose where it went when you made it, and it has not moved since.
Draftline keeps no library of its own and no hidden copy — the file you can
see is the book.

## Backing up

Copy the file. That is the whole procedure.

There is no export step, no folder to keep together, and nothing to
reassemble. A `.draftline` from any machine opens on any other.

Worth doing before anything irreversible: a big structural edit, a find and
replace across the book, or an import.

## Syncing

A `.draftline` in Dropbox, OneDrive, Google Drive or iCloud works, with one
thing to understand.

The file is rewritten whole on every save. A sync client sees a changed file
and uploads all of it, so a large book with cover art in it means a large
upload every few minutes while you are writing. It works; it is just heavier
than you might expect.

If a book feels slow to sync, the usual cause is artwork. Print-ready wrap
artwork is tens of megabytes, and **Book Details & Editions** offers to link
it rather than keep a copy inside the book — linking keeps the file small.

**Never edit the same book from two machines at once through a sync folder.**
Draftline can stop two windows on *one* machine opening the same book. It
cannot see another computer, and a sync client resolving two versions of one
file does it by picking a winner.

## Two windows, two books

The same book cannot be open twice. The second window is refused and the one
already holding the book comes forward.

Two different books at once is fine — **New Window** in the menu. It opens on
the start screen so you can choose.

## Where else Draftline writes

- **Settings and your recent books** live in your user profile, not in any book.
- **Downloaded updates** go to a cache folder and can be deleted freely.
- **Read Aloud voices**, if you use it, are downloaded once and kept.

None of that is needed to open a book. Move the `.draftline` to a new machine
and everything about the book comes with it.
