# Plugins

**Plugins** in the menu, or the Plugins section of Settings.

<!-- SCREENSHOT: reference/plugins.png
     The plugins screen listing bundled and installed plugins. -->

## What they are

Plugins add features to Draftline. Some are bundled with the application and
some you install.

A plugin can add panels to the tool rail and screens of its own. What a
plugin cannot do is anything you have not enabled: plugins are off unless
turned on, individually.

## Installing

The plugins screen lists what is bundled and what is installed. Where a
community catalogue is available you can browse it from here.

## Before installing one

A plugin is code running inside your writing application, with your
manuscript in front of it. Install plugins the way you would browser
extensions: from somewhere you trust, because you want that specific thing,
and not because it was listed.

Draftline is open source and so are its bundled plugins, so what they do is
readable by anyone who cares to look.

## Turning one off

Same screen. A disabled plugin stops running and its panels disappear;
nothing it wrote into your book goes with it.
