# Plugins

**Plugins** in the menu, or the Plugins section of Settings.

<!-- SCREENSHOT: reference/plugins.png
     The plugins screen listing the bundled plugins. -->

## What they are

Plugins add features to Draftline: panels in the tool rail, and screens of
their own.

Every plugin available today is bundled with the application. The plugins
screen lists them, and each is off until you turn it on.

## The community marketplace

A placeholder. Community plugins are planned; there is no date, and nothing to
install from it yet.

## Turning one off

Same screen. A disabled plugin stops running and its panels disappear. Nothing
it wrote into your book goes with it.
